Прототип созданный для провождение ивентов.

Показатели рельсотрона-
Общий урон- 100 ед(95 механический урон, 5 термического урона).
Стреляет рельсотроновым импульсом.
Состояния охлаждения(кд перед следующим выстрелом) 5 секунд.
Заряжаться со скоростью импульсного карабинаMK2.

За основу ношения в рукха рельсотрона был взяты текстурки импульсного карабинаMK2.
